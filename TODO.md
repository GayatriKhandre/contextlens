# ContextLens acceptance outcomes

- [ ] A real person can describe a difficult situation and see goal, facts, constraints, stakeholders, assumptions, and unknowns.
- [ ] The app asks a useful clarification question and supports both answering and skipping while preserving unknown status.
- [ ] The app presents perspectives, connections, contradictions, blind spots, reframings, options, trade-offs, and synthesis.
- [ ] The app makes it explicit that the human makes the final decision, then saves that decision and shows it in history/replay.
- [ ] Personal context is optional and only used after explicit opt-in.
- [ ] The local AI status is honest: Ollama/Gemma is shown as unavailable when unavailable, with a functional deterministic fallback.
- [ ] API health, analysis, continuation, decision, replay, and personal-context routes are implemented.
- [ ] Keyboard navigation, visible focus, readable contrast, labels, and responsive mobile layouts are implemented.
- [ ] Tests and end-to-end smoke checks pass.

Out of scope for this MVP: voice input, external search, account authentication, and optional partner integrations not actually implemented and tested.
